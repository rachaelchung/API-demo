import requests

def get_weather(city):
    # YOUR KEY GOES HERE
    api_key = "PASTE_YOUR_API_KEY_HERE"
    
    # The base URL for the 'Current Weather' service
    base_url = "http://api.openweathermap.org/data/2.5/weather"

    # We use a dictionary for the 'parameters' of the request
    # 'units=metric' gives us Celsius instead of Kelvin
    params = {
        "q": city,
        "appid": api_key,
        "units": "metric" 
    }

    try:
        response = requests.get(base_url, params=params)
        
        # This checks for 404s or 500s automatically
        response.raise_for_status() 
        
        data = response.json()

        # Navigating the JSON dictionary to find the data we want
        temp = data["main"]["temp"]
        desc = data["weather"][0]["description"]
        city_name = data["name"]

        print(f"--- Weather in {city_name} ---")
        print(f"Temperature: {temp}°C")
        print(f"Condition: {desc.capitalize()}")

    except requests.exceptions.HTTPError:
        print("City not found or API key is still activating.")
    except Exception as e:
        print(f"An error occurred: {e}")

# Try it out!
user_city = input("Enter a city name: ")
get_weather(user_city)

That sounds like a fun project! Music apps are a great way to learn because the data is structured and generally "clean."

However, finding a truly free lyrics API is trickier than it used to be due to licensing restrictions. Here are your best options for 2026, ranked by ease of use for a beginner:

### 1. LRCLIB (The "Hidden Gem" Choice)

This is currently the most developer-friendly option for a small app. It is an open-source database that provides both plain text and **time-synced lyrics** (great if you want to make a karaoke-style app).

* **Pros:** Totally free, no API key required, and no rate limits for small projects.
* **Cons:** The database is crowdsourced, so very obscure songs might be missing.
* **Best for:** Someone who wants to start coding *immediately* without waiting for API approvals.

### 2. Genius API (The "Data Rich" Choice)

Genius is famous for its crowdsourced annotations. While their API is free and very powerful, it technically doesn't return the **full lyrics** in the JSON response (only a URL to the lyrics page) to protect their web traffic.

* **Pros:** Huge database; gives you "behind the scenes" facts and artist info.
* **Cons:** You’ll need to use a "scraper" library (like `lyricsgenius` for Python) to actually get the words.
* **Best for:** Apps that want to show song meanings or trivia.

### 3. Musixmatch (The "Professional" Choice)

This is the industry standard (used by Spotify and Apple). They have a free "Basic" tier.

* **Pros:** Incredible accuracy and coverage.
* **Cons:** The free tier only lets you show **30% of the lyrics** per song and requires an API key.
* **Best for:** Learning how to handle API keys and restrictive data limits.

**Lyrical Keepsakes** is a minimalist, aesthetic digital scrapbook where users "collect" the lines of music that stay with them. Instead of a standard music player, it is a gallery of **animated poetry cards.**

* **The Curator (Search):** A clean interface to find songs using the **LRCLIB API**.

* **The Vault (Storage):** A personal library saved in the browser’s **LocalStorage**, so your collection persists without needing a complex database.
